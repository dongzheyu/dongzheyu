# JetCPPTeam

JetCPPTeam 是一个专注于开源开发、工具创新和青少年编程普及的技术团队。我们致力于创造高效、易用的软件工具，服务于游戏玩家、普通开发者以及初学者等不同人群。团队鼓励协作创新，注重工程质量与持续成长。

---

## 团队简介

JetCPPTeam 组建于 2024 年，由一群热爱技术、富有探索精神的开发者组成。我们的使命是用现代化编程技术解决实际痛点，同时推动更多人体验技术带来的价值与乐趣。

我们拥有多样化的项目方向，涵盖游戏辅助工具、系统自动化、Web 平台、编程学习工具等。

---

## 主要项目

**Minecraft-ToolsII**  
现代化的 Minecraft 管理工具，支持 Java 和基岩版，简化环境配置。  
项目链接：https://github.com/dongzheyu/Minecraft-ToolsII

**GoodMinecraft**  
高性能 Minecraft 整合包，提升多设备兼容性和游戏体验。  
项目链接：https://github.com/dongzheyu/GoodMinecraft

**github-clone**  
多终端批量克隆 GitHub 仓库工具。  
项目链接：https://github.com/dongzheyu/github-clone

**English-Listen-WinUI**  
基于 WinUI3 的英语听力测评软件，适用于语言学习场景。  
项目链接：https://github.com/dongzheyu/English-Listen-WinUI

**JetCPPWebsite**  
JetCPPTeam 技术博客与成员展示平台。  
项目链接：https://github.com/dongzheyu/JetCPPWebsite

**MinGW-win64-GCC-install**  
自动化安装 MinGW GCC 编译器于 Windows 的便捷工具。  
项目链接：https://github.com/dongzheyu/MinGW-win64-GCC-install

**blog2**  
基于 TypeScript 和 Vue 的新一代内容管理/博客平台。  
项目链接：https://github.com/dongzheyu/blog2

更多项目，详见 [全部仓库](https://github.com/dongzheyu?tab=repositories) 页面。

## 技术栈

**编程语言支持**  
- Go  
- Vue（含生态：Vue CLI、Vite、Pinia 等）  
- HTML / CSS / JavaScript

- C#  

**框架/平台**

- WinUI 3（C#）
